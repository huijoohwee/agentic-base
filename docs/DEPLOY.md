# Deployment boundary

There is no hosted deployment in this increment. The supported runtime is a static browser demo with same-origin IndexedDB. Local demonstration uses `npm run dev`; Shoply can bundle the bounded Base browser artifact into its existing offline static assets. The owner selected MIT for this repository's owner-authored source after provenance review. Consumer distribution remains bound to exact Git commits; `package.json` stays private, so this does not publish to a package registry. Public repository visibility and the required `check` branch policy are separate GitHub settings that must be applied and read back for the release. Production host selection, storage recovery, and any new consumer pin/cutover remain gated.

The source workflow may prove checks for an exact commit. It does not authorize package publication, static-site upload, a remote object store, an edge runtime, schema migration, or production promotion. Revisit this boundary only with a selected product owner, exact target and artifact, a verified free/FOSS path, backup/restore proof, and a separate operator instruction.
