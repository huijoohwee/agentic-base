# Deployment boundary

There is no hosted deployment in this increment. The supported runtime is a static browser demo with same-origin IndexedDB. Local demonstration uses `npm run dev`; Shoply can bundle the bounded Base browser artifact into its existing offline static assets. The owner selected MIT for this repository's owner-authored source after provenance review. GitHub reports the repository is public and `main` requires the `check` status context (`strict=false`), verified by provider readback and `npm run doctor` on 2026-10-23. Consumer distribution remains bound to exact Git commits; `package.json` stays private, so this does not publish to a package registry. Production host selection, storage recovery, and any new consumer pin/cutover remain gated.

The source workflow may prove checks for an exact commit. It does not authorize package publication, static-site upload, a remote object store, an edge runtime, schema migration, or production promotion. Revisit this boundary only with a selected product owner, exact target and artifact, a verified free/FOSS path, backup/restore proof, and a separate operator instruction.

## Sheets artifact boundary

`npm run build:sheets` seals a self-contained static workbook under `sheets/dist/`. Its manifest binds source file digests, Design System revision/profile/license and a sorted path/byte/SHA-256 output inventory; the manifest excludes itself from its aggregate digest. The site release owner must additionally bind the exact protected Base commit. It must verify that same candidate on preview before any authorized activation at `airvio.co/agentic-sheets/` and generated mirror publication at `huijoohwee/huijoohwee:content/agentic-sheets/`. No Base command here activates that site or writes the Prod mirror. The inherited site release controller, current cost proof, production environment authorization, exact route readback and predecessor remain separate gates.
